# Create the Specification/Statement of Work for the Smart Expense Tracker Project

Here is the specification from a fictitious, ABC & Co Inc for a Software Company to develop a Smart Expense Tracker:

## Specification for the Smart Expense Tracker

- The application should be able to add an expense with these set of fields: a customer name, amount in USD, and category (e.g. Food, Travel or Shopping)
- The application should be on a web page and should be supported on all the major web browsers.
- Display the expense entered by the user as a line below the data entry field.
- Show the total amount spent.
- Allow the user to delete and expense.
- Show a simple message for invalid inputs, such as an empty name or an amount that is zero or negative.
- The expense data should be stored in a csv file so that so that it persists any time the web page is closed and re-opened.
